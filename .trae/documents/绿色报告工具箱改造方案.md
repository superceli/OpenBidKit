# 绿色报告工具箱改造方案

## Context

当前 OpenBidKit 是"哲元投标工具箱"，包含技术方案、可研报告、商务标、查重、废标项、AI 评标、投标机会等大量投标专用功能。用户要求将整个项目改造为纯粹的"绿证报告工具箱"，删除所有投标相关代码，只保留绿色报告生成主功能和必要的基础设施（知识库、报告模板、资源、插件、设置），并将品牌标识从"易标/哲元投标"全面改为"绿证报告工具箱"。

## 新菜单结构

最终保留的菜单（[menuConfig.ts](file:///d:/develop/OpenBidKit/client/src/app/menuConfig.ts)）：

| 菜单 | SectionId | 子项 | 说明 |
|------|-----------|------|------|
| 绿色报告生成 | `green-report` | - | 主功能，独立顶级（已在上一阶段建成） |
| 知识库 | `knowledge-base` | `document-knowledge-base` | 文档知识库，企业信息检索 |
| 报告模板 | `template-settings` | `my-templates`、`new-template` | 复用现有导出排版配置，文案改为"报告模板" |
| 资源下载 | `resources` | - | 保留 |
| 插件管理 | `plugin-manager` | - | 保留 |
| 设置 | `settings` | - | AI 配置、关于等 |

**删除的菜单**：`bid-generation`（含 `technical-plan`/`existing-plan-expansion`/`feasibility-report`/`business-bid`）、`bid-check`（含 `duplicate-check`/`rejection-check`/`ai-evaluation`）、`bid-opportunity`、`image-knowledge-base`（开发中未落地）。

## 品牌标识全改

| 位置 | 旧值 | 新值 |
|------|------|------|
| package.json name | `yibiao-client` | `lvcert-client` |
| package.json description | `哲元投标工具箱独立桌面客户端` | `绿证报告工具箱独立桌面客户端` |
| build.productId | `com.yibiao.openbidkit` | `com.lvcert.report` |
| build.productName | `哲元投标工具箱` | `绿证报告工具箱` |
| build.artifactName | `Yibiao-${version}...` | `Lvcert-${version}...` |
| index.html title | `哲元投标工具箱` | `绿证报告工具箱` |
| main.cjs 窗口 title | `哲元投标工具箱` | `绿证报告工具箱` |
| preload bridge key | `window.yibiao` | `window.lvcert` |
| 资源协议 scheme | `yibiao-asset` | `lvcert-asset` |
| GPU trial arg | `--yibiao-trial-hardware-acceleration` | `--lvcert-trial-hardware-acceleration` |
| 资源图标文件 | `yibiao_256.ico` | 保留文件名或重命名为 `lvcert_256.ico`（可选） |

`window.yibiao` → `window.lvcert` 全局重命名涉及约 43 个 renderer 文件，使用统一替换。

## 执行顺序

1. **品牌标识**：package.json、index.html、main.cjs（title/scheme/arg）、preload.cjs（bridge key）、全局 `window.yibiao` → `window.lvcert` 替换、ipc.ts `YibiaoBridge` → `LvcertBridge`
2. **菜单/路由**：menuConfig.ts、navigation.ts、AppRouter.tsx、Sidebar.tsx、traffic.js
3. **Electron Main**：删除投标 IPC 文件、修改 index.cjs、删除投标 service 文件、修改 taskService.cjs、pluginContext.cjs
4. **数据库**：sqliteDatabase.cjs（schemaVersion + migration + createInitialSchema）、workspace_schema.sql
5. **Renderer features**：删除投标 feature 目录
6. **清理**：删除 `shared/prompts/rejectionPrompts.ts`、`analysisPrompts.ts` 等投标专用 Prompt
7. **AGENTS.md**：更新范围说明，移除投标相关章节

5. 启动 `npm run dev` 验证：侧边栏只显示 6 个菜单，绿色报告生成功能正常，知识库/报告模板/资源/插件/设置可访问
